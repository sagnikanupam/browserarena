VERIFIED INTERACTIONS - PAIRED USER REQUESTS WITH MODEL ATTEMPTS
================================================================

This file contains verified interactions from the BrowserArena pipeline where two models attempted to complete user requests. Each entry includes:
- User task/request
- Attempt 1 details (model, outcome, GIF link)
- Attempt 2 details (model, outcome, GIF link) 
- Vote/preference information from human evaluators

Data Structure:
- Each interaction contains "states" with two model attempts
- GIFs show browser automation recordings
- Log IDs link to detailed logs and prompts
- Verified interactions have been cleaned for model identity

Source Files:
- FastChat/verified_conv_log/verified_interactions-clean.json (126 total interactions)
- FastChat/gifs/ (GIF recordings of each attempt)
- FastChat/logs/ (detailed execution logs)
- FastChat/prompts_and_outputs/ (model prompts and outputs)

File Name Pattern:
All related files use the format: DD_MM_YYYY_HH_MM_SS_XXX
Where XXX is a 3-letter identifier that links:
- The GIF recording
- The execution log
- The prompts/outputs JSON
- The verified interaction entry

For complete interaction details, reference:
- FastChat/verified_conv_log/verified_interactions-clean.json for full conversation data
- preference-agreement-surveys.ipynb for analysis of human evaluator feedback
- Qualtrics survey data for detailed human preference votes

This file structure enables linking user requests with model performance comparisons and human evaluation data for research on AI agent capabilities in web browsing tasks.
